Setup · TQHB Text Agents Shortcut

One-time setup · 5 minutes

What this does

The TQHB report page builds a daily queue of agents to text. With the "Run Shortcut" button, the page hands that queue to an iOS Siri Shortcut on your iPhone, which then fires all the SMS in one go — instead of you tapping Send for each one.

End result: review the daily report → tap one button → all messages send from your iPhone with your number as the sender → done in ~10 seconds for 20 agents.

Before you start

  • iOS 16 or newer (any iPhone from 2018+)
  • The Shortcuts app installed (built into iOS — if you deleted it, re-download from App Store)
  • 5 minutes

Build the Shortcut on your iPhone

1

Open Shortcuts → tap ＋ to create new

Top-right corner. You'll see a blank canvas with "Add Action" in the middle.

2

Add action: Get Contents of URL — replace with this

Actually skip — we use the Shortcut Input instead. The page passes text data via the shortcuts:// URL scheme. So:

Tap ＋ Add Action → search "Get Dictionary" → choose Get Dictionary from Input.

Action 1: Get Dictionary from Shortcut Input
3

Get the queue array out of the dictionary

Add action → search "Get Dictionary Value" → choose Get Dictionary Value.

  • Get: Value
  • For: queue
  • In: tap the variable → choose Dictionary (from step 2)
Action 2: Get Value for queue in Dictionary
4

Loop through each agent: Repeat with Each

Add action → search "Repeat" → choose Repeat with Each. The input is the Dictionary Value from step 3 (the queue array).

You'll see Repeat with Each Item in [Dictionary Value] and an End Repeat marker. All next actions go between these two markers.

5

Inside the loop: pull phone and message from each entry

Add action Get Dictionary Value — Value for phone in Repeat Item. Rename this magic variable to RecipientPhone (tap the variable chip → rename).

Add another Get Dictionary Value — Value for message in Repeat Item. Rename to MessageBody.

Inside loop:
  Get Value for phone in Repeat Item → RecipientPhone
  Get Value for message in Repeat Item → MessageBody
6

Send the message: Send Message

Add action → search "Send Message" → choose Send Message (the Messages-app one, not "Send Email").

  • Message: tap → pick MessageBody variable
  • Recipients: tap → pick RecipientPhone variable
  • Tap Show More → toggle Ask Before Sending to OFF
Critical: If "Ask Before Sending" stays ON, you'll get a confirmation prompt for every single message — defeating the whole point. Toggle it OFF.
7

Optional: Show Notification when done

After the End Repeat marker (not inside), add → search "Show Notification" → choose Show Notification. Title: TQHB queue sent. Body: All messages dispatched.

8

Name it EXACTLY: TQHB Text Agents

Top of the screen, tap the title field → set to TQHB Text Agents. Case and spacing matter — the page calls this exact name via URL scheme.

Tap Done top-right.

Final shortcut should look like this

┌─ TQHB Text Agents
│
├─ 1. Get Dictionary from Shortcut Input
├─ 2. Get Value for queue in Dictionary
├─ 3. Repeat with Each Item in Dictionary Value
│   ├─ 4. Get Value for phone → RecipientPhone
│   ├─ 5. Get Value for message → MessageBody
│   └─ 6. Send Message MessageBody to RecipientPhone
│            [Ask Before Sending: OFF]
├─ 7. End Repeat
└─ 8. Show Notification: "TQHB queue sent"

Test it

  1. Open tqhb.github.io/daily-lead-generator on your iPhone Safari
  2. Tap 🎯 Run Shortcut button in the header
  3. Confirm the "Hand off N messages…" prompt
  4. Safari hands off to Shortcuts → loop fires
  5. Open Messages app — every agent should have a sent thread
First-run iOS prompt: the first time the Shortcut runs, iOS may ask "Allow Run Shortcut?" Tap Always Allow so future runs are silent.

Share with Vivek (one-tap install)

Once your Shortcut works end-to-end:

  1. Open Shortcuts app → long-press the TQHB Text Agents card
  2. Tap Share → iCloud Link
  3. iCloud generates a link like https://www.icloud.com/shortcuts/...
  4. Send the link to Vivek via WhatsApp/iMessage
  5. Vivek taps the link on his iPhone → Add Shortcut → done
Note for Vivek: first time he uses the page's Run Shortcut button, iOS may prompt "Allow Untrusted Shortcuts" or "Allow Run Shortcut." Both can be set to Always Allow in Settings → Shortcuts.

Troubleshooting

SymptomFix
"Couldn't open Shortcut" alertName mismatch. Verify the Shortcut is named EXACTLY TQHB Text Agents (no extra spaces).
Asks confirmation per messageToggle Ask Before Sending OFF inside the Send Message action.
Some messages sent, then stoppediOS rate-limits ~10 SMS/minute. For 30+, run twice with the status filter (e.g. Active first, Under Contract second).
"Could not run Shortcut from this app"Settings → Shortcuts → Advanced → enable Allow Running Scripts.
"Allow Untrusted Shortcuts" greyed outRun any Shortcut once from the Shortcuts app to enable the toggle.
SMS sent from wrong numberSettings → Messages → iMessage account → set sending number to Vivek's primary line.

What gets sent

The page passes JSON to the Shortcut. Each queue entry has:

{
  "generated_at": "2026-05-25T18:30:00Z",
  "count": 12,
  "queue": [
    {
      "name": "Virginia Espinoza",
      "phone": "+13466008833",
      "message": "Hi Virginia, this is Vivek...",
      "type": "active",
      "mls_list": "10357889"
    },
    {
      "name": "Edward McClintick",
      "phone": "+18882271009",
      "message": "Hey Edward, this is Vivek, local investor. I see it is under contract...",
      "type": "uc",
      "mls_list": "96512970"
    }
    ...
  ]
}

Under Contract listings carry type: "uc" so the message body uses the "if the current buyer doesn't perform" wording. Agents with mixed status appear twice (one entry per type).
